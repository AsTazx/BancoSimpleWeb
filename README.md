\# 🏦 BancoSimpleWeb



Aplicación web de banco simple desarrollada en \*\*ASP.NET WebForms\*\* con C#.



\## ✅ Funcionalidades

\- Depósitos y retiros

\- Historial de movimientos

\- Validación de saldo insuficiente



\## 🛠️ Tecnologías

\- ASP.NET WebForms (.NET Framework 4.8)

\- C#

\- CSS3



\## 🚀 Cómo correrlo

1\. Clonar el repositorio

2\. Abrir `BancoSimpleWeb.sln` en Visual Studio

3\. Presionar F5
